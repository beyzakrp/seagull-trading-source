# Project instructions

This repository contains only the Seagull Trading marketing frontend.
Preserve the existing design and the five routes: /, /services/, /work/, /qr-menu/, /about/.
There are no admin, portal, authentication, QR generation, dynamic menus, API, database or upload features.
Use Next.js static export. Run npm run build to generate out/ and node --test tests/rendered-html.test.mjs to verify it.
Do not restore removed backend features unless explicitly requested.
